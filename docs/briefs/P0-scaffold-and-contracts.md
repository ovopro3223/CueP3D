# P0 — Scaffold and shared contracts (Fable, Wave 0)

## Goal

A monorepo in which every later pipeline can start independently: frozen contracts, a shared stage, sample assets, tooling, and a fixture proxy video for P4.

## Deliverables

- Root: `package.json` (pnpm workspaces: `packages/*`, `apps/*`, `bench`), `pnpm-workspace.yaml`, `tsconfig.base.json` (strict, ESM, `moduleResolution: bundler`), `.editorconfig`, `.gitignore`, `.npmrc`, Vitest and Playwright base configs, ESLint flat config (typescript-eslint, minimal rules), Prettier.
- `packages/manifest`: zod schema for §5.2, exported TS types, `validateManifest(json): Manifest`, `resolveUrl(manifestUrl, relative)`. Tests: valid fixture passes; each required field missing fails with a readable path.
- `packages/stage`: §5.3 API on three.js (pin one minor version, r17x). `fitDistance`, `frameIndexForAzimuth`, `azimuthForFrameIndex`, `createStage` with `RoomEnvironment` PMREM for `studio-neutral`, ACES/neutral tone mapping, sRGB output, overlay quad rendered with an orthographic pass in the same frame. Tests (Vitest, Node, math only): round-trip azimuth↔frame for 72 and 36 frames; camera position for θ=0 is on +Z; θ=π/2 is on +X.
- `packages/cli`: `bin` entry `understudy` with `build` subcommand parsing the flags in §7 and calling three functions that P1–P3 will export: `buildGeometry`, `renderProxyFrames`, `encodeProxy`. Stubs throw `NotImplemented` until Wave 2 wiring.
- `samples/`: download script (`scripts/fetch-samples.mjs`) that pulls `Avocado.glb`, `BoomBox.glb` and `WaterBottle.glb` (all CC0-1.0; see D-005a for why WaterBottle and not DamagedHelmet) from KhronosGroup/glTF-Sample-Assets at commit `8f492390ddc7a2ae221a1369ef560589cf8c70fb`, writes `samples/LICENSES.md` with attributions pulled from each model's `metadata.json`. Samples are git-ignored; the script runs in CI.
- `fixtures/proxy-fixture.av1.mp4`: a 72-frame, 256×256, GOP-8 AV1 clip made from a numbered-frames pattern (ffmpeg `testsrc2` + `drawtext` of the frame index) so P4 can assert decoded frame ↔ index without P2/P3. Also `fixtures/proxy-fixture.vp9.mp4` and `fixtures/avif/000..071.avif`. Generated by `scripts/make-fixtures.mjs`; committed (small).
- `scripts/assert-free-codecs.mjs`: ffprobe every media file under given dirs; exit 1 unless `codec_name ∈ {av1, vp9}`; AVIF files probed as `av1`. Also greps `packages/`, `apps/`, `bench/`, `scripts/` for `/libx264|x265|h264|hevc|avc1|hvc1|hev1/i` and fails on hits outside `docs/`.
- `.github/workflows/ci.yml`: ubuntu-latest, pnpm, Node 20; `apt-get install ffmpeg`; install KTX-Software release `.deb` for `toktx`; `pnpm install --frozen-lockfile`, lint, typecheck, test, fetch samples, build one sample, codec gate, Playwright smoke. Committed but only runs when the owner pushes.
- `docs/briefs/`, `docs/reports/`, `docs/reviews/`, `docs/audits/`, `docs/change-requests/` directories with `.gitkeep`.
- `README.md` skeleton (P8 completes), `LICENSE` (MIT), `CONTRIBUTING.md` (short).

## Acceptance

- `pnpm install && pnpm -r typecheck && pnpm -r test` green on Windows (owner machine) and documented for Linux.
- `node scripts/assert-free-codecs.mjs fixtures` passes; a deliberately added H.264 file (local only, not committed) fails it.
- `understudy build --help` prints the §7 flags.
