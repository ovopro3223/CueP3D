How to actually throttle the network

A page cannot slow down its own network requests. To see CueP3D's advantage on a slow connection, open DevTools → Network panel → set throttling to “Slow 3G” or “Fast 3G” before reloading. The “Simulate low-end device” toggle above instead overrides the viewer's own device-tier policy (CPU/GPU heuristics), independent of network speed.
